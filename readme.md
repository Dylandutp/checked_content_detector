# Checked Content Detector | 打勾內容辨識系統

## 功能簡介 | Features
本程式應用於發工指令單的項目內容辨識。辨識流程可分為三個步驟:  
This program is designed to **detect and recognize checked content** on work order forms.  
The recognition process can be divided into **three steps**:

1. 偵測指令單上已被打勾的方格  
   Detect the checkboxes that have been marked on the form.

2. 擷取出對應方格區塊的內容，並進行切片，每個切片僅保留含有所需內容的區塊。  
   同時將這些切片依據其在指令單上的位置進行分類。  
   Extract the corresponding checkbox regions, **slice them into smaller images**, keeping only the areas that contain relevant content.  
   These slices are then **classified based on their positions** on the form.

3. 對切片內容進行OCR辨識並以JSON文件的形式儲存。  
   Perform **OCR (Optical Character Recognition)** on each slice and save the recognition results in **JSON format**.

## 使用方法 | Usage
將原始資料解壓縮後直接放入 `input` 資料夾內，執行 `app.py` 即可。  
After extracting the raw data, place it inside the `input` folder and run `app.py`.

執行完畢後，紀錄結果的 JSON 檔案會儲存於 `output` 資料夾內，同時可於 `debug` 資料夾內查看暫存的切片檔案。  
Once the process is complete, the JSON files will be saved in the `output` folder,  
and you can view the intermediate slice files in the `debug` folder.

> **注意 / Note:**  
> 原始資料解壓後的格式應如下圖所示：  
> The extracted folder structure **must follow the format below**:
> ```
> 資料夾 / Folder
> ├─工令號1 / Work Order #1
> │  └─發工指令單1.pdf / Instruction Form #1.pdf
> ├─工令號2 / Work Order #2
> │  └─發工指令單2.pdf / Instruction Form #2.pdf
> ...
> ```

## 模組簡介 | Modules
本程式中有 3 個主要模組：`checkbox_finder`, `ocr`, `config_reader`  
There are **three main modules** in this program: `checkbox_finder`, `ocr`, and `config_reader`.

### **1. `checkbox_finder`**
- 尋找發工指令單中被勾選的選項，並將選項區塊切片保存成 JPG 檔，方便 OCR 辨識使用。  
- Detects the checked boxes on the form, slices them into smaller regions, and saves them as **JPG files** for OCR processing.

### **2. `ocr`**
- 對 `checkbox_finder` 模組切出來的切片進行文字辨識，並將結果以 JSON 檔案的形式儲存。  
- Performs **text recognition (OCR)** on the slices generated by the `checkbox_finder` module  
  and saves the results as **JSON files**.

### **3. `config_reader`**
- 讀取使用者的設定，目前主要用於將程式內部的相對路徑轉換為絕對路徑。  
- Reads user configurations. Currently, it is primarily used to **convert relative paths to absolute paths** within the program.
